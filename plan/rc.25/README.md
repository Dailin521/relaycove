## 功能地图与设计差异

| 设计入口 | rc.25 行为 |
| --- | --- |
| 聊天、频道、账户/设置、成员、显式消息搜索、回复、复制、失败重试、附件、@、发送 | 复用现有真实功能。 |
| 联系人、通知、文件、更多、置顶、会话通知、Emoji、语音、主动截图、发送选项、反应、转发、收藏、消息删除 | 保留可点击入口，显示无副作用的“功能暂未开放”。 |
| 头像照片、在线状态、成员角色、Delivered/Read/Deleted/Retrying | 无权威数据来源，不实现或伪造。 |

布局采用“标题栏 + 导航轨 + 会话栏 + 聊天区”三列主结构；成员和设置都以聊天区域上的覆盖面板打开，成员抽屉只在宽度 `>=1400px` 可用。输入卡的正文区可在上沿拖拽调整，工具栏和发送操作保持在卡片底部。
