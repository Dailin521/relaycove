# RelayCove UI 重构落地方案 v1.0

## 1. 背景

项目：RelayCove

定位：面向小团队的轻量级、自托管 Windows 私域聊天工具。

当前主分支已具备 Windows WPF 客户端基础能力，UI
采用三栏聊天结构。本次改造目标不是简单美化，而是建立一套可持续扩展的桌面聊天
UI 体系。

参考方向：

-   微信 Windows 客户端的信息组织方式
-   Slack / Discord 的团队协作结构
-   Linear / Notion 的现代桌面软件视觉

目标：让 RelayCove 从"功能可用"提升到"商业级桌面应用体验"。

------------------------------------------------------------------------

# 2. 总体布局设计

窗口结构：

    RelayCove Window
    │
    ├── Navigation Rail
    │
    ├── Conversation Panel
    │
    └── Chat Panel

固定三栏：

## 左侧 Navigation Rail

职责：低频入口。

包含：

-   用户头像
-   聊天
-   联系人
-   频道
-   通知
-   文件
-   设置
-   更多

建议宽度：72px。

设计原则：

-   图标优先
-   当前状态明显
-   不展示复杂文字

------------------------------------------------------------------------

# 3. 会话列表设计

Conversation Panel

建议宽度：320-380px。

结构：

    搜索框

    筛选区域

    公开频道
     ├ 产品设计
     └ 运营动态

    私有频道
     ├ 发布准备
     └ 研发小队

    私聊
     ├ 林乔
     └ 程远

ConversationItem 必须支持：

-   图标/头像
-   名称
-   最新消息预览
-   时间
-   未读数量
-   静音状态
-   当前选中状态

状态：

-   Normal
-   Hover
-   Selected
-   Unread
-   Disabled

------------------------------------------------------------------------

# 4. 聊天区域设计

Chat Panel 是主要视觉区域。

## Header

包含：

-   当前频道/用户名称
-   描述
-   成员数量
-   搜索
-   置顶
-   通知
-   更多

------------------------------------------------------------------------

## 消息流

支持：

-   普通文本消息
-   图片
-   文件
-   引用回复
-   系统消息
-   失败重试

消息状态：

    Draft
     ↓
    Sending
     ↓
    Sent
     ↓
    Delivered

    Failed
     ↓
    Retry

------------------------------------------------------------------------

# 5. 输入区域设计

固定底部。

支持：

-   多行输入
-   @成员
-   Emoji
-   图片附件
-   文件附件
-   语音入口
-   发送按钮

发送按钮：

主色：RelayCove Green

状态：

-   Normal
-   Sending
-   Disabled

------------------------------------------------------------------------

# 6. 视觉规范

## 色彩

主色：绿色系。

背景：

-   浅灰
-   白色卡片

避免：

-   大面积渐变
-   高饱和颜色
-   传统企业软件蓝色边框

------------------------------------------------------------------------

## 圆角

统一：

-   面板 12px
-   输入框 10px
-   按钮 8px

------------------------------------------------------------------------

# 7. 组件拆分建议

核心组件：

    NavigationRail
    ConversationPanel
    ConversationItem
    ChatHeader
    MessageList
    MessageItem
    AttachmentCard
    Composer

每个组件独立管理：

-   UI状态
-   样式
-   交互

避免页面级代码堆积。

------------------------------------------------------------------------

# 8. 资源规范

不推荐传统大量切图。

不要：

-   背景图片
-   按钮图片
-   聊天气泡图片

推荐：

-   SVG 图标
-   WPF Style
-   ControlTemplate
-   Theme

需要资源：

    icons/
     avatar-demo/
     sample-files/

# 9. Codex 执行要求

AI 执行顺序：

## Phase 0

分析当前 UI 实现。

输出：

CURRENT_UI_ANALYSIS.md

确认：

-   当前窗口结构
-   控件关系
-   可复用组件
-   风险区域

------------------------------------------------------------------------

## Phase 1

实现基础布局。

优先：

1.  NavigationRail
2.  ConversationPanel
3.  ChatPanel

保持现有业务逻辑。

禁止修改：

-   服务端 API
-   SignalR
-   DTO
-   数据库

------------------------------------------------------------------------

## Phase 2

完善交互。

包括：

-   Hover
-   Selected
-   未读
-   Loading
-   Error
-   Retry

------------------------------------------------------------------------

## Phase 3

截图验收。

必须验证：

-   1280x720
-   1600x900
-   1920x1080

------------------------------------------------------------------------

# 10. 验收标准

UI 达到：

-   三栏结构清晰
-   信息密度合理
-   视觉接近现代桌面聊天软件
-   所有状态可表达
-   不影响现有功能
-   WPF代码保持可维护

最终目标：

RelayCove 成为一个具有完整产品感的 Windows 桌面聊天客户端。
