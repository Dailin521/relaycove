# 工作日志

每次功能变更都在交付用户验证前记录，包括新增、修复、移除、影响行为的重构和界面调整。规则见 [AGENTS](../../AGENTS.md)。按月维护 `YYYY-MM.md`，不为每个小问题建立单独文件。

- [2026-09](2026-09.md)

## 条目模板

```markdown
## YYYY-MM-DD — 问题或功能名称

- 需求：用户希望改变的实际行为。
- 变化：最终实现和影响范围；必要时链接关键文件。
- 验证：实际执行的命令/人工反馈与结果；没有运行就如实说明。
- 限制：仍需验证的设备、场景或已知问题；没有则写“无新增已知限制”。
- 交付：待用户验证 / 用户已确认 / 已提交（提交号）/ 已发布（版本链接）。
```

同一天同一问题的后续修正更新原条目；跨天续作新增条目并引用前文。用户确认或发布后更新交付字段。较长历史只能按可核实证据回补，标注“历史整理”和来源，不编造逐日修改时间或验收。不得保存凭据、账号、消息原文或工具输出转储。
