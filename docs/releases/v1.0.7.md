# RichChat 1.0.7

本次更新改善图片、附件和表情操作，并修复搜索与窗口退出问题。

- 图片右键新增“复制图片”，可直接粘贴到其他应用；GIF 复制为静态首帧。
- 已下载且仍在本地的附件显示“打开”。下载期间禁止重复点击，按钮边框从顶部顺时针显示进度。
- 修复表情滚动加载不触发、追加后位置跳动及快速滚动异常；空关键词也可继续浏览。
- 改善透明 GIF 的显示，去除纯图片消息的气泡底色和边框。
- 左侧“+”增加查看自己所在全部群聊的入口；修复私聊搜索，搜索结果显示日期时间。
- 调整消息文字顶部留白，改善阅读效果。
- 加强 Windows 退出清理和单实例窗口恢复，处理退出残留及再次启动无窗口的情况。

版本 1.0.7，构建号 14。旧下载历史缺少附件标识时，需重新下载一次才能自动显示“打开”。

提供 Windows x64 中文安装器、自包含 ZIP、SHA-256 校验文件和自动更新清单。安装器未签名；升级前请保存草稿并从托盘退出旧版本。

完整本地验证通过：1764 项测试，Release 构建及自包含打包完成。未运行真实 Realm 写入、干净虚拟机安装升级或故障 Win10 设备复现验证。
