# RelayCove 2.3.0

RelayCove V2.3 聚焦 Windows MAUI 客户端的日常响应速度、文件传输和桌面体验，仍直接连接 Zulip Realm，不引入 RelayCove 服务端、代理或第二套消息后端。

## 本版更新

- 私聊与私有群聊切换优先复用本机视图缓存，连续历史加载保持当前阅读位置。
- 搜索支持消息、文件、图片、视频和链接分类、匹配高亮与结果定位。
- 支持粘贴截图；输入框尺寸保存在本机，发送后立即插入本地消息。
- 主窗口关闭到托盘，托盘菜单可完整退出。
- 附件上传显示进度；大文件使用 Zulip TUS 分块续传，避免断线后从头上传。
- 附件下载支持进度、取消、重试、默认目录和逐次询问；标题栏新增最近下载中心。
- 优化登录起始页，并可打开当前 Realm 的 Zulip 官方注册页面。
- 修正下载完成/失败提示点：打开下载中心即视为已查看，不影响历史记录和失败重试。

## 下载与运行

1. 下载 `RelayCove-2.3.0-win-x64.zip` 和 `RelayCove-2.3.0-win-x64.sha256`。
2. 校验 ZIP 的 SHA-256。
3. 解压后运行 `RelayCove.App.exe`。

## 发布说明

- 仅支持 Windows 11 x64。
- 这是自包含、无安装器、未签名的正式发布 ZIP；Windows SmartScreen 可能显示提示。
- 应用退出后不会继续接收消息，不包含后台推送、自动更新、MSIX 或代码签名。
- 本版界面与交互已由用户在 Visual Studio/实际工程中确认。
- 本次按个人 MVP 快速发布，仅执行受影响测试和必要发布检查；未运行 Full、Live、Web、干净 VM、安装器或签名门禁。
