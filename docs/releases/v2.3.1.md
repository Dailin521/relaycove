# RichChat 2.3.1

RichChat 2.3.1 是 Windows MAUI 客户端的小版本体验更新，继续直接连接 Zulip Realm，不引入自研服务端、代理或第二套消息后端。

## 本版更新

- 产品显示名称统一为 RichChat；工程名、应用 ID 和本机持久化键保持兼容。
- 左侧会话列表补充鼠标悬浮反馈：未选中行移入时显示浅色背景，当前会话继续保持独立选中态。
- 优化标题栏按钮的默认、悬浮和按下反馈，点击后不保留选中底色。

## 下载与运行

1. 下载 `RichChat-2.3.1-win-x64.zip` 和 `RichChat-2.3.1-win-x64.sha256`。
2. 校验 ZIP 的 SHA-256。
3. 解压后运行 `RichChat.exe`。

## 发布说明

- 仅支持 Windows 11 x64。
- 这是自包含、无安装器、未签名的正式发布 ZIP；Windows SmartScreen 可能显示提示。
- 应用退出后不会继续接收消息，不包含后台推送、自动更新、MSIX 或代码签名。
- 本版界面与交互已由用户在 Visual Studio/实际工程中确认。
- 本次按个人 MVP 快速发布，仅执行受影响测试和必要发布检查；未运行 Full、Live、Web、干净 VM、安装器或签名门禁。

当前开发与验证边界见仓库中的 `docs/ai/STATUS.md`；发布历史以 Git tag 和 GitHub Release 为准。
