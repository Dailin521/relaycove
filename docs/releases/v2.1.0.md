# RelayCove 2.1.0

RelayCove V2.1 是首个 MAUI 正式版本后的 Windows 桌面体验增量，继续直接连接 Zulip Realm，不引入 RelayCove 服务端、代理或第二套消息后端。

## 本版更新

- 普通消息正文支持 Windows 原生鼠标拖选与复制。
- 增加“收藏的消息”入口、分页和精确消息定位。
- 修正 reaction 按钮右侧裁切及表情面板锚点。
- 图片消息仅保留预览，右键可通过消息菜单下载原图。
- 增加常驻 Windows 系统托盘图标、未读悬浮预览、原位闪烁提醒和点击跳转会话。

## 下载与运行

1. 下载 `RelayCove-2.1.0-win-x64.zip` 和 `RelayCove-2.1.0-win-x64.sha256`。
2. 校验 ZIP 的 SHA-256。
3. 解压后运行 `RelayCove.App.exe`。

## 发布说明

- 仅支持 Windows 11 x64。
- 这是自包含、无安装器、未签名的正式发布 ZIP；Windows SmartScreen 可能提示风险。
- 暂无后台推送、自动更新、MSIX、代码签名、SSO、多账号、`@` 候选或 presence。
- 应用关闭后不会继续接收消息；系统通知和托盘提醒仅在客户端运行时工作。
- 干净 Windows 11 VM、正式最终密码登录，以及收藏消息/Reaction 面板的两项独立精确位置人工确认仍是开放门禁。

完整开发与验证边界见仓库中的 `docs/ai/STATUS.md` 和 V2.1 发布任务记录。
