# RelayCove 2.2.0

RelayCove V2.2 继续改进 Windows 原生 MAUI 体验，直接连接 Zulip Realm，不引入 RelayCove 服务端、代理或第二套消息后端。

## 本版更新

- 稳定当前会话收到实时消息时的底部跟随动画，避免视口闪动、反复动画和虚拟化行跳变。
- 显示 Zulip 官方在线、忙碌和离线状态，不从消息或窗口活动推测。
- 当前用户可选择在线、忙碌或官方隐身模式；写入不会自动重试。
- 增加 Zulip 个人状态文字/emoji 显示，并提供七个官方预置状态及清除入口。

## 下载与运行

1. 下载 `RelayCove-2.2.0-win-x64.zip` 和 `RelayCove-2.2.0-win-x64.sha256`。
2. 校验 ZIP 的 SHA-256。
3. 解压后运行 `RelayCove.App.exe`。

## 发布说明

- 仅支持 Windows 11 x64。
- 这是自包含、无安装器、未签名的正式发布 ZIP；Windows SmartScreen 可能显示提示。
- 应用关闭后不会继续接收消息，不包含后台推送、自动更新、MSIX 或代码签名。
- Stage 38 最终视觉确认、Stage 32 收藏消息精确定位、Stage 34 reaction 面板定位、干净 Windows 11 VM 和最终正式密码登录仍是开放门禁。
- 安装器、MSIX 和代码签名尚未实施或验收。

完整开发与验证边界见仓库中的 `docs/ai/STATUS.md` 和 V2.2 发布任务记录。
