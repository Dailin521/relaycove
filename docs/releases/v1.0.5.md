# RichChat 1.0.5

本版本以 SVN RichChat 主线为基础，增加 GitHub Release 更新检查，使用构建号 12；延续 SVN 的 1.0.x 显示版本，不按历史 GitHub 2.4.0 比较新旧。

- 默认启动时检查更新，每个新版只提醒一次，可在“设置 → 通用”关闭。
- “设置 → 关于”支持手动检查、下载、取消和打开安装包。下载完成不自动安装或重启。
- 安装包及更新清单来自同一个 GitHub 正式 Release，下载和打开前检查文件长度与 SHA-256。
- 发布 Windows x64 自包含 ZIP、中文 EXE 安装器、校验文件及 `update-win-x64.json`。推荐使用安装器；升级前请处理未发送的草稿。

验证：`pwsh ./scripts/verify.ps1 -Mode Full` 通过，Core 293、Zulip.Client 311、Data 41、App 980，共 1625 项；Release 构建无错误，保留 7 个现有 XamlC 性能提示。自包含发布、运行文件和秘密检查通过；自动更新与安装器逻辑已独立只读复核。

表情包搜索与个人收藏不包含在本版本。未运行 Live、真实 Realm 写入、干净 VM 或实际安装升级验收，安装包未签名。更新提醒及下载的真实客户端操作由用户本地验证。
