# RichChat 2.4.0

RichChat 2.4.0 是 Windows MAUI 客户端的交互与可靠性更新，继续直接连接 Zulip Realm，不引入自研服务端、代理或第二套消息后端。

## 本版更新

- 打开对应会话或权威未读下降后停止本轮托盘闪烁；未读徽标仍按服务器状态保留。
- 使用 Windows App SDK 单实例策略：重复启动恢复现有窗口；托盘退出保留正常清理并提供超时兜底。
- 会话头像适度右移；账户菜单保留只读状态显示，不再提供在线状态或个人状态修改入口。
- 文件选择、拖拽和截图粘贴统一即时顺序上传；上传完成前禁止发送，失败只允许显式重试或移除。
- 空搜索不再触发本机扫描或服务器请求；输入后立即显示本机结果，并保留服务端防抖查询。
- 消息快捷栏精简为本人“编辑 + 更多”、他人“更多”；完整菜单继续保留全部操作，并更新圆圈双引号引用图标。
- 隐藏等待投递提示；服务器明确拒绝显示红色失败，网络结果未知显示黄色风险提示，均不自动重发。

## 下载与运行

1. 下载 `RichChat-2.4.0-win-x64.zip` 和 `RichChat-2.4.0-win-x64.sha256`。
2. 校验 ZIP 的 SHA-256。
3. 解压后运行 `RichChat.exe`。

## 发布说明

- 仅正式支持 Windows 11 x64。
- 这是自包含、无安装器、未签名的正式发布 ZIP；Windows SmartScreen 可能显示提示。
- 应用退出后不会继续接收消息，不包含后台推送、自动更新、MSIX 或代码签名。
- 本版运行 Release Full 门禁、自包含打包、必要文件检查和秘密扫描；不运行 Live、Web、干净 VM、安装器或签名门禁。
- UI 自动验收使用离线 `preview.invalid` 数据，不登录、不访问或写入真实 Realm。

当前开发与验证边界见仓库中的 `docs/ai/STATUS.md`；发布历史以 Git tag 和 GitHub Release 为准。
