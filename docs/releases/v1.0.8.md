# RichChat 1.0.8

- 表情面板调整为“表情 / gif / 收藏”，每次打开默认显示小表情；gif 页保留原搜索和滚动加载功能。
- 私聊搜索只展示服务器结果，不再混入本地缓存。重新搜索清空旧结果；无命中和请求失败分别提示。中文搜索依赖服务器的中文全文搜索配置。
- 修复升级时自动关闭应用只隐藏到托盘、导致安装等待的问题。安装器确认后按安装目录结束旧实例，新版应用也支持安装器正式退出通知。升级前请先保存未发送内容。
- 补齐功能说明和开发工作流，今后每次功能修改均记录工作日志。

版本 1.0.8，构建号 15。提供 Windows x64 中文安装器、自包含 ZIP、SHA-256 校验文件和自动更新清单。安装器未签名，安装后不会自动启动。

安装器关闭流程已通过隔离进程测试：拒绝关闭时不继续安装，确认后结束目标实例并替换文件，其他目录同名进程不受影响。真实设备安装升级、代码签名和真实 Realm 写入未作本轮专项验证。
