# RichChat 1.0.6

本版本构建号为 13，基于已发布的 1.0.5 更新通道继续发布；GitHub Release 中的安装器、校验文件与 `update-win-x64.json` 必须来自同一次打包。

- 同步 SVN r5027 的群聊创建提示、Windows 空闲状态上报和协议兼容改动。
- 右键消息菜单恢复“复制”：优先复制选中文字，无选区时复制正文；文字排版增加行距与气泡留白。
- 增加搜索、默认和收藏表情面板。搜索结果只显示图片；默认表情增大单元格并收紧面板高度；收藏保留改名和移除。
- 支持从 GitHub Release 检查、下载和打开新版安装器；下载前核对长度及 SHA-256。
