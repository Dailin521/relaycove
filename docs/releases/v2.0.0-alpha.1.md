# RelayCove 2.0.0-alpha.1

RelayCove 的首个原生 MAUI 版本，直接连接 Zulip Realm，不引入 RelayCove 服务端、代理或第二套消息后端。

## 主要能力

- Windows 原生统一会话列表：一对一/self 私信与受支持的私有群聊。
- 50 条历史分页、实时事件、已读/未读、断线恢复和本机 SQLite 缓存。
- 文本与附件、reaction、本人消息编辑/删除、收藏、引用和统一服务器/本地搜索。
- Zulip 12.1 完整 Unicode 表情目录与 shortcode 显示。
- 私有群聊创建、成员与群设置，以及严格的服务端权限边界。
- Windows 系统通知、任务栏闪烁和权威未读徽标。

## 下载与运行

1. 下载 `RelayCove-2.0.0-alpha.1-win-x64.zip` 和 `RelayCove-2.0.0-alpha.1-win-x64.sha256`。
2. 校验 ZIP 的 SHA-256。
3. 解压后运行 `RelayCove.App.exe`。

## 预发布说明

- 仅支持 Windows 11 x64。
- 这是自包含、无安装器、未签名的 ZIP；Windows SmartScreen 可能提示风险。
- 暂无后台推送、自动更新、MSIX、代码签名、SSO、多账号、`@` 候选或 presence。
- 应用关闭后不会继续接收消息；系统通知仅在客户端运行时工作。
- 最终干净 Windows 11 VM 启动和正式最终密码登录门禁仍未关闭。

完整开发与验证边界见仓库中的 `docs/ai/STATUS.md` 和发布任务记录。
