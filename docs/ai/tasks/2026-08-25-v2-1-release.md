# RelayCove 2.1.0 — V2.1 release

Status: completed; formally published on 2026-08-25

## Purpose

- Synchronize the current `main` delivery and publish the Stage 31–36 increment as the formal Windows 11 x64 `v2.1.0` GitHub Release.
- Preserve the existing `v2.0.0-alpha.1` tag and release unchanged.
- Treat V2.1 as a release checkpoint; do not mark the complete ordered V2 optimization plan finished.

## Release scope

- Selectable ordinary message text with native Windows drag selection and copy.
- Saved-message entry, pagination and precise message anchoring.
- Reaction button clipping correction and trigger-relative reaction-picker positioning.
- Image-only message presentation and contextual original-image download.
- Persistent Windows tray icon, unread-only hover preview, in-place attention blink and click-through conversation navigation.
