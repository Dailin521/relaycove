# 客户端图片预览与会话导航补强

## 任务定义

- **状态：** `已完成`
- **范围：** 图片消息自动预览、私聊成员展示、频道分组折叠、UI 设计约束沉淀
- **非目标：** 不修改服务端 API、SignalR、Shared DTO、数据库或消息可靠性语义

## 实现结果

- 图片附件即使尚未落盘，也会在可见消息项中显示预览位；控件首次加载时自动复用现有下载、缓存、授权、完整性校验和安全解码链路，下载成功后自动显示缩略图，失败仍保留附件附近的重试入口。
- 私聊成员栏显示服务端返回的全部参与成员，隐藏仅适用于频道的“可添加成员”目录，并明确显示参与人数。
- 公开频道、私有频道和私聊分组使用可折叠 Expander；折叠状态按分组名称保留，刷新或虚拟化重新物化后不影响会话选择、未读数和数据权限。
- 新增 [`docs/ui-design-guidelines.md`](../../ui-design-guidelines.md)，集中记录布局、成员、消息/图片、输入区、视觉规范与验证边界。
