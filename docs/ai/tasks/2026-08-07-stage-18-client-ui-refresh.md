# 阶段 18：rc.23 客户端 UI 重构

## 任务定义

- **任务名称：** 阶段 18 rc.23 客户端 UI 重构
- **状态：** `进行中`
- **目标版本：** `1.0.0-rc.23`
- **基准提交：** `ce95daf`
- **工作分支：** `agent/stage-18-client-ui-refresh`
- **需求来源：** `rc.23执行范围.txt`
- **相关方案章节：** 阶段 8、阶段 9、16、17、21.1–21.5

### 目标

在不改变服务端协议、权限和可靠发送语义的前提下，将 Windows 客户端重构为现代团队聊天软件的三栏布局，改善频道导航、消息阅读、输入、成员管理、视觉规范和状态表达。

### 已知事实

- `已验证`：基准 Fast 构建 0 警告、0 错误；Shared 70、Server 353、Client 1,164、Updater 38，共 1,625 项测试通过。
- `已验证`：会话列表当前为未分组的单一 ListBox；消息模型尚无连续消息合并标记。
- `已验证`：回复、@提及、附件、发送失败重试、新消息线、发送后输入清理和私有成员管理已有生产实现与回归测试。
- `已验证`：仓库当前没有 UI 截图或像素渲染工具；本任务需要新增仅基于 WPF RenderTargetBitmap 的内置快照入口。
- `已验证`：owner 禁止使用 Windows 应用控制能力。

### 范围

- 必须实现：
  - 公开频道、私有频道、私聊分组，类型图标、选中状态、未读徽标，分组旁创建入口。
  - Slack/Mattermost 风格消息流、连续消息合并、回复/提及/分隔线、附件卡片和就地失败重试。
  - 固定底部多行输入区，集中附件/回复/预览状态，单独移除附件，清晰发送状态。
  - 可展开右侧成员栏，成员搜索、添加和移除；小窗口自动收起。
  - 统一颜色、圆角、间距、字号、按钮状态、空状态和简短状态表达。
  - 1280×720、1600×900、1920×1080 内置渲染验证及改造前后截图。
  - Release 构建 0 警告、0 错误。
- 允许修改：
  - `src/RelayCove.Client/`
  - `tests/RelayCove.Client.Tests/`
  - `docs/ai/` 与本任务所需验证脚本/证据
- 明确不做：
  - 不改变服务端 API、SignalR、共享 DTO、数据库或消息同步协议。
  - 不减少聊天、频道、私聊、附件、@提及、搜索、更新和成员管理功能。
  - 不使用 Windows 应用控制、UI Automation 或桌面控制能力。

### 验收标准

- [ ] 三栏布局与分组导航完成，低频账户功能位于底部区域。
- [ ] 消息、输入、附件、回复、提及和失败重试按范围完成且原有功能不回归。
- [ ] 成员栏可展开并支持私有频道成员搜索、添加和移除，小窗口自动收起。
- [ ] 三种目标尺寸内置渲染通过，输入区和关键按钮不裁切。
- [ ] 提供改造前后截图对比。
- [ ] 定向测试、Fast、Full 与 Release 构建通过。
- [ ] UI 确认后再构建 rc.23、推送、合并并发布内部更新。

### 停止并询问

- 需要改变公共协议、权限、数据库、消息可靠性语义或引入大型依赖时停止。
- 发现与本任务无关的工作区修改、失败基线、秘密或不可逆外部写入时停止。
- 推送、合并和内部发布在 UI 验收完成后按 owner 明确确认执行。

## 任务结果

### 修改摘要

- 客户端账户态切换为浅灰画布上的白色内容区；左侧会话栏固定为公开频道、私有频道、私聊三组，空组仍保留创建入口，频道类型图标、选中态和未读徽标均由现有展示模型驱动。
- 消息流改为无左右气泡的 Slack/Mattermost 风格，支持同发送者五分钟内连续消息合并；保留日期线、新消息线、回复引用、链接、缩略图/附件卡片与就地失败重试。
- 输入区固定在聊天底部，回复、@提及、附件预览集中在输入区；十个附件预览和提及候选在小窗口下使用内部滚动，单个移除和发送状态保持原有事件链路。
- 频道成员管理由全屏遮罩改为右侧抽屉，增加成员搜索、头像、昵称、账号、能力/成员标签、添加和危险操作移除；窗口缩窄到 1400 以下自动收起。
- 账户、更新、退出和连接诊断收进左栏底部展开器；正常同步状态隐藏，连接状态使用短中文。
- 新增基于 WPF `RenderTargetBitmap` 的内置快照测试与三档真实 Window client-area 尺寸/响应式断言。

### 决策与限制

- `已验证`：没有修改 Shared/Server DTO、数据库、SignalR 或消息可靠发送语义。
- `未验证`：当前共享 `ConversationParticipantListResponse` 不包含逐成员 `ConversationMemberRole` 字段，因此 UI 只能如实显示“可管理成员/频道成员”能力标签，不能伪造逐成员频道角色；若要求真实逐成员角色，必须另开协议切片并重新评审范围。
- `未验证`：未使用 Windows 应用控制或 UI Automation；截图均由 WPF 内置渲染入口生成。
