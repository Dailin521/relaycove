# RelayCove 2.2.0 — V2.2 release

Status: in progress; verification and publication pending

## Purpose

- Publish current `main` Stage 37–38 increments as the formal Windows 11 x64 `v2.2.0` GitHub Release.
- Preserve `v2.1.0` and all earlier tags/releases unchanged.
- Keep all previously open visual, clean-VM, password-login, installer and signing gates explicit.

## Release scope

- Stable one-shot native bottom-follow animation for realtime messages in the active near-bottom conversation, without changing authoritative unread state.
- Zulip official `active` / `idle` / `offline` presence display for supported one-to-one conversations.
- Current-user online/busy/invisible control using official presence and `presence_enabled` semantics.
- Separate Zulip personal status text/emoji display and seven official preset write options.
