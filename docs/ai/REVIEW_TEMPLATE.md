# AI 独立审查模板

本模板用于认证、迁移、消息可靠性、通知、更新和部署等关键任务。审查者默认只读，不修改文件。

## 审查输入

- **目标提交或范围：** `<commit、branch 或 diff>`
- **任务文件：** `<docs/ai/tasks/...>`
- **相关方案章节：** `<章节或链接>`
- **必须执行的验证：** `<命令或人工场景>`

## 审查提示词

```text
作为独立审查者，阅读 AGENTS.md、相关工程方案章节、任务文件和完整差异。
先确认验收标准，再检查正确性、安全性、兼容性、并发/幂等、错误处理、日志和测试。
运行允许的只读验证。不要修改文件，不要推测未看到的实现，也不要复述变更摘要。
只报告可操作的问题；每个问题必须包含严重级别、文件与行号、触发条件、影响和证据。
如果没有问题，明确写“未发现可操作问题”，并列出实际运行与未运行的验证。
```

## 输出格式

### Findings

按严重级别排序：

- `[P0-P3] 标题` — `文件:行号`
  - 触发条件：
  - 影响：
  - 证据：
  - 建议修复：

### Verification

| 状态 | 命令或场景 | 结果 |
| --- | --- | --- |
| `已验证` | `<命令>` | `<结果>` |
| `未验证` | `<检查>` | `<原因>` |

### Residual Risk

- `<审查范围外或无法验证的风险；没有则写“无”>`
