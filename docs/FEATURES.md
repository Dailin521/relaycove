# RichChat 功能说明

更新：2026-09-17。依据：当前 `1.0.8`（构建 `15`）源码、产品计划、已有测试和版本记录。服务器搜索、表情页签和安装器退出修正自 1.0.8 起生效。本文件描述已实现的产品行为，不把“代码存在”视为所有设备均已验收。验证状态见 [STATUS](ai/STATUS.md)，逐次变化见[工作日志](worklogs/README.md)。

## 1. 产品与平台

RichChat 是直接连接 Zulip Realm 的 Windows MAUI 客户端，当前分发 Windows x64 自包含程序和中文安装器。产品目标为 Windows 11 x64；Windows 10 兼容问题已有针对性处理，但故障设备复现与实际安装升级未完成专项验证。工程、命名空间和缓存标识保留 RelayCove 名称。

账号、群成员、权限、消息与实时事件以 Zulip 为准。本地 SQLite 只作缓存；没有独立聊天服务器、代理或 BFF。历史 Web 不再作为产品开发、验证或发布对象。

## 2. 登录与本地数据

- 使用 Realm、邮箱和密码登录；密码用于换取 API key，凭据通过平台安全存储保存。
- 启动恢复已解锁的账号缓存，优先显示本地会话与消息，后台连接服务器；离线可浏览已缓存历史。
- 当前同时使用一个账号。注销删除安全凭据并锁定对应缓存，不删除服务器消息。
- 本机缓存和收藏按账号隔离。清理会话记录只影响该账号的本地缓存，不等于撤回或批量删除服务端历史。
- 网络中断后恢复同步；消息发送等非幂等写入不自动重试，结果未知时不能当作明确失败再次发送。

## 3. 会话与群聊

| 入口/操作 | 行为与限制 |
|---|---|
| 左侧统一会话列表 | 一对一私信、发给自己的消息及受支持的群聊；置顶优先，其余按最新消息排序 |
| 左侧搜索 | 查找会话和联系人等本地导航结果；与当前聊天内搜索分开 |
| 左侧“+” | 新建聊天/群聊，以及查看自己所在群聊的入口 |
| 自己所在群聊 | 展示当前账号已订阅且符合产品群聊条件的会话，不是全服务器公开群目录 |
| 新建群聊 | 填写名称并选择至少两名其他活跃成员；由服务端决定是否创建成功 |
| 群资料与成员 | 查看资料和成员；编辑、邀请、移人、转让、退出、解散等操作依权限显示/执行，不能凭本地列表推断权限 |
| 已读/未读 | 打开对应会话并到达最新位置后才确认已读；悬停、托盘预览和单纯获得焦点不清除未读 |
| 会话历史 | 向上分页；当前位于底部时显示实时追加消息，浏览旧消息时保持位置 |

群详情还支持当前账号本地备注、个人静音/置顶和群内搜索；群名/公告及管理操作依服务端确认的单一群主身份启用。转让群主后退出，解散为先移除其他成员再退出，都有确认步骤。权限结构不支持可靠判定单一群主时只提供个人设置。

群聊只对应已订阅、活动、私有、非 Web 公开并要求空话题的 Zulip 频道，内部为 `ChannelTopic(channelId, "")`。当前不提供公开频道、命名话题或多人私信入口。

联系人页展示当前会话已可靠获知的活跃用户，不是完整成员目录；页面没有点击联系人直接发起聊天的绑定。左侧“已保存”查看收藏消息，与本地表情收藏分开。

## 4. 消息输入与操作

- 文本输入支持 Enter 发送、Ctrl+Enter 换行，输入框内保留选区、剪贴板和输入法行为。
- 支持附件发送、引用回复、表情反应、消息收藏及受权限约束的编辑/删除；界面成功状态以服务器结果为准。
- 消息右键“复制”优先复制当前消息内选中的文字；无选区时复制显示正文，保留换行，不含姓名、时间或原始 HTML。纯图片不显示正文复制项。
- 打开右键菜单时保存选区快照；关闭菜单、切换目标或会话时清除，防止复制到上一条。正文仍支持 Ctrl+C。
- 正文行高随字号调整，含表情行允许自然增高；气泡保持左右对齐。单行列表摘要与正文使用不同布局。
- 非输入区域主要使用鼠标操作，原生列表键盘导航禁用；不将输入区快捷键推导为全局菜单快捷键。

## 5. 图片与文件

### 图片

图片消息显示预览，可打开查看原图。纯图片消息不显示额外气泡底色和边框；透明 GIF 使用逐帧透明渲染，动画显示与普通图片解码分开处理。

图片右键菜单包含“复制图片”“下载原图”“收藏为表情”，并保留适用的消息操作。

- “复制图片”读取图片内容后写入 Windows 剪贴板，不复制链接、不要求先保存文件；以保留 alpha 的 PNG 位图交付给目标应用。
- GIF 的“复制图片”复制静态首帧；“下载原图”和表情收藏保留原始动图。粘贴后的透明效果取决于目标应用支持，不能将静态剪贴板行为描述为复制动图。
- 读取或剪贴板操作失败时显示错误；获取图片期间切换账号则放弃写入。

### 文件下载与打开

| 状态 | 按钮与行为 |
|---|---|
| 没有匹配的有效本地记录 | 显示“下载”；保存位置按下载设置处理 |
| 正在下载 | 显示“下载中”，禁用重复点击；边框从 12 点钟方向顺时针按实际字节比例推进 |
| 总大小未知 | 使用顺时针循环动画，不显示伪造的百分比 |
| 下载成功且文件存在 | 显示“打开”，使用系统关联程序打开 |
| 文件被删除/移动 | 下次状态刷新或点击检测后恢复下载行为 |
| 取消或失败 | 结束进度动画，允许重新下载；打开失败给出相应提示 |

识别依据是当前账号下载历史里的附件来源标识和真实文件路径，不按文件名猜测，也不扫描整个磁盘。历史只保留最近 20 条；被移除或淘汰的记录，以及旧版本没有来源标识的记录，不能自动关联为“打开”，重新下载后可识别。下载完成、消息投影与窗口重新激活时刷新状态，点击前再次检查文件。

下载中心可查看近期记录、打开文件、定位文件夹、移除记录或清空记录；移除记录不会删除磁盘文件。下载目录与是否每次询问保存位置在设置中配置。

## 6. 表情面板

输入区表情面板从左到右为“表情”“gif”“收藏”。每次打开先显示“表情”（原默认小表情），不记住上次停留页；第二项“gif”保留原搜索表情的内容与分页功能，与消息 reaction 选择器分开。

| 页面 | 操作 |
|---|---|
| 表情 | 组织小表情插入输入光标处，不作为独立图片消息发送 |
| gif | 关键词可留空，按名称匹配 ChineseBQB 目录；结果只显示图片，无名称、收藏图标和分类选择，底部不显示说明文字 |
| 收藏 | 本机导入图片、使用已收藏图片，以及改名/移除；也可从聊天图片菜单加入收藏 |

- 搜索/收藏的大图独立上传并发送，不消耗正在编辑的文字和附件草稿。准备或上传时切换账号/会话会取消；发送请求已经发出后结果未知，不自动重试。
- 每批追加 60 张，列表第一次滚动超过可滚动距离的 90% 且有更多结果时触发下一批；同次越界不反复触发。追加保持当前滚动偏移，不跳回顶部。
- 这里的分页从已获取的目录匹配结果中追加，图片按需读取，不代表每次滚动重新执行外部搜索 API 请求。
- 来源为 ChineseBQB 的公开目录；不含图片文字识别。目录缓存最长 24 小时，媒体缓存预算 200 MiB，最多四路图片下载，首次获取需网络。
- 收藏是按账号隔离的本机原始副本，按内容哈希去重，不随缓存淘汰或注销删除；删除导入源文件不影响收藏。
- 支持 PNG/JPEG/WebP/GIF，单张上限 25 MiB，发送还受 Realm 附件限制约束。GIF 保留原始动图，面板悬停预览，卸载时停止。
- 收藏成功不在聊天区产生常驻提示卡片。未接入其他付费表情服务，第三方内容不随安装包分发。

## 7. 消息搜索

聊天标题栏的搜索用于当前会话，与左侧导航搜索分开；另有全局搜索入口。结果可按全部、消息、文件、图片、视频、链接筛选，包含发送人、内容/图片及 `yyyy-MM-dd HH:mm` 本地日期时间。

搜索列表只显示服务端返回并符合会话范围和筛选条件的消息，不追加本地缓存。输入非空关键词后延迟约 300ms 执行服务端搜索，也可 Enter 或点击“搜索”立即提交；关键词可留空。每次新搜索先清空上一轮结果，无命中显示无结果，请求失败显示错误，不使用本地消息替代。服务端每页最多请求 50 条，有更多结果时可继续加载；打开空搜索框不会自动查询，需点击搜索或按 Enter。旧查询结果有过期校验，首次搜索完成后通过 UI 线程更新列表。

搜索覆盖范围取决于服务端权限和匹配规则；离线时显示请求失败，不提供本地搜索降级。左侧导航搜索仍保留原本的本地匹配行为。文件/链接筛选不承诺读取附件内部文字。

## 8. Windows 窗口、提醒与状态

- 关闭按钮按现有行为收进托盘，应用仍运行；托盘“退出”或主窗口实际销毁进入真正退出流程。
- 安装器 Restart Manager 的询问阶段只同意关闭，不提前退出；收到带 `ENDSESSION_CLOSEAPP` 的正式退出确认才进入真正退出，取消通知不退出。普通关闭仍收进托盘。
- 真正退出统一异步清理，并在清理开始前启动约 3 秒的进程兜底；清理异常不阻断后续退出。
- 保留单实例标识 `RichChat.Main`。托盘点击和再次启动尝试显示、恢复并激活原窗口；初始化中的恢复重试最长约 5 秒，退出中不重新显示。
- 激活转交等待最长约 5 秒；旧实例已退出则重新竞争所有权，旧进程仍在但转交失败则提示并结束本次启动，不自动终止其他实例。
- 本地生命周期诊断只记录版本、Windows 构建号、PID、退出阶段和激活结果，不记录账号或聊天内容。
- 系统通知、任务栏与托盘提醒仅在应用运行时有效；真正退出后没有后台推送。
- 在线/忙碌/离线来自 Zulip presence；个人文字/emoji 状态独立设置。连续 5 分钟无 Windows 用户输入时自动忙碌，恢复输入后回到活跃；手动忙碌/离线优先，使用其他软件也算活跃。群聊和 self-DM 不伪造聚合在线状态。

## 9. 设置与自动更新

设置默认进入外观，窄窗口使用顶部横向导航。具体可用项受平台能力、登录状态与权限限制。

| 页面 | 当前设置 |
|---|---|
| 外观 | 系统/浅色/深色主题、正文 12–16px、会话栏宽 264–352px，支持恢复界面偏好默认值 |
| 通用 | Windows 开机启动，默认关闭；显示系统配置或不可用状态 |
| 通知 | 免打扰、Windows 横幅、消息预览、任务栏闪烁、任务栏/托盘未读红点；免打扰仍保留未读 |
| 存储 | 修改/打开下载目录、每次下载前询问、确认后清除当前账号本机缓存 |
| 账户 | 当前用户和 Realm、注销、启动时检查更新开关；不展示密码或 API key |
| 关于 | 当前版本、手动检查更新、下载/取消下载、打开安装包 |

外观与下载偏好是本机设置；清理缓存不删除服务端消息。

更新默认在完整启动后异步检查 GitHub 正式 Release，不依赖 Realm 登录；可在账户设置关闭。“关于”保留手动检查、下载、取消和打开安装包，每个新版只在窗口可见时提醒一次。

只接受 `Dailin521/relaycove` 的配套 `update-win-x64.json` 和 Windows x64 安装器；以递增构建号判断新版，核对产品、版本、文件名、长度和 SHA-256。历史 `2.4.0` 不会因显示版本更大而被当成当前 `1.0.x` 更新。下载完成不自动安装或重启。

安装器安装到当前用户目录，提供快捷方式和卸载入口，自带运行时。卸载保留账户数据/缓存，需要清除凭据时先注销。安装器未签名，升级前应先处理未发送草稿。

安装前检查目标目录的 `RichChat.exe`。检测到运行进程后明确询问是否结束，默认选择否；确认后通过保留的进程句柄核对完整路径并结束该实例，最多等待 5 秒，避免旧版只隐藏到托盘而卡住升级。其他路径同名进程不会被终止。无法访问或核实进程身份时阻止继续并提示手动退出；因此权限不足的同名进程也可能阻止自动处理。静默安装仅显式传入 `/CLOSEAPPLICATIONS` 才允许该步骤，`/NOCLOSEAPPLICATIONS` 优先。结束旧进程可能丢失尚未保存的内容，不承诺旧版草稿自动保存。

## 10. 未提供的能力与验证边界

当前不提供多账号并行、SSO、公开频道/命名话题/多人私信入口、@ 候选、typing、AI、后台 push、静默安装更新、移动端或 Mac/Linux 客户端、MSIX 和代码签名。源码中存在的旧频道/话题命令不等于当前用户入口已经开放。

例如 MainPage 仍有通用频道设置弹层，但当前统一会话列表没有触发该频道菜单的生产绑定；其中的公开频道发现、订阅和高级频道管理不列入本版可用功能。

1.0.7 的完整本地验证及用户反馈见 STATUS；Win10 故障机器、干净 VM 安装升级和原生剪贴板跨应用兼容性不能由单元测试替代。不要把待验证项写成已修复设备清单。
